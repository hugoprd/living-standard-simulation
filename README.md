# Descrição

Projeto de modelo de Machine Learning para identificar como os indicadores socioeconômicos de um local (Rio de Janeiro) influenciam nos indicadores de segurança/criminalidade.

# Engenharia de Dados

## Coleta de Dados

A coleta de dados foi feita manualmente, sem WebScrapping, devido ao fato da necessidade de poucas e específicas tabelas de dados públicas.

# Description

Machine Learning model project to indentify how the socioeconomics indicators of a place (Rio de Janeiro) can alternate on security/criminality indicators.

# Data Engineering

## Data Collection

The data collection was made manually, without WebScrapping, because on the fact of the necessity of some and especific tables of public data.
